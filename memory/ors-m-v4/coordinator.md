## Planning requirements from confirmed experience

When you split this task into sub-graphs and choose their skills, follow each requirement whose condition holds for this task. Each one comes from failures of earlier tasks that were repaired and confirmed by a rerun.

1. When a step matches: The object is already held and both object and receiver OBBs are available.; A receiving cavity is already exposed; any subsequent closing operation belongs to another skill. -- assign that sub-graph the skill `placing-held-objects-inside` (its main script `place_inside` as one `main` node; route on `status`: done -> `completed`, failed -> the `fail` node running `raise_failure`) instead of composing baseline grasp / transport scripts for it.
2. When a step matches: The object is already held and object, destination, and grasp-time references are available.; The instruction requires supported placement, stacking, adjacent placement, or a supported slide beneath an overhang. -- assign that sub-graph the skill `placing-carried-objects-on-supports` (its main script `place_on_support` as one `main` node; route on `status`: done -> `completed`, failed -> the `fail` node running `raise_failure`) instead of composing baseline grasp / transport scripts for it.
